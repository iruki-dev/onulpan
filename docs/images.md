# 뉴스 이미지 사용 가이드

2026-10-03 · @RuKi

오늘판의 이미지 기능은 이 문서를 그대로 따른다. 출처 목록과 분야별 순서는 `rules/image_sources.yaml`에,
사용 전 체크리스트는 `worker/images/policy.py`에 코드로 옮겨져 있다. 이 문서를 고치면 두 곳도 같이 고친다.

## 기본 원칙

뉴스 이미지는 이용 조건이 확인된 출처에서 가져오고, 출처가 지정한 크레딧을 그대로 표기합니다.

- **자유 이용 출처를 먼저 찾습니다.** 기업·기관 발표를 다루는 기사에는 보도용 제공 출처를 사용합니다.
- **개별 이미지의 표기를 기준으로 판단합니다.** 같은 사이트 안에서도 이미지마다 조건이 다를 수 있습니다.

## 자유 이용 출처

출처 표시만 하면 모든 기사에 쓸 수 있는 이미지입니다.

| 출처 | 주요 이미지 | 사용 조건 |
| --- | --- | --- |
| 공공누리 0·1유형 (정부·지자체·공공기관) | 행사, 정책, 인물, 장소 | 출처 표시 (0유형은 조건 없음) |
| [공유마당](https://gongu.copyright.or.kr/) | 만료·기증 저작물, CC 이미지 | 저작물별 이용 조건 확인 |
| [NASA](https://www.nasa.gov/multimedia/guidelines/index.html), NIH, NOAA 등 미국 연방기관 | 우주, 의학, 기후, 정부 활동 | 기관이 직접 제작한 이미지 사용, 출처 표시, 기관 로고는 별도 규정 확인 |
| [ESA/허블](https://esahubble.org/images/) | 천문 | CC BY 4.0, 출처 표시 |
| [Wikimedia Commons](https://commons.wikimedia.org/) | 인물, 장소, 사물 전반 | CC0, CC BY, CC BY-SA 파일 선택, 파일별 표기대로 크레딧 |
| [Unsplash](https://unsplash.com/license), Pexels, Pixabay | 개념·일반 삽화 | 출처 표시 권장 |
| 자체 제작 그래픽 | 지도, 차트, 타임라인, 인포그래픽 | 원자료 출처 표기 |

## 보도용 제공 출처

기업과 기관이 언론 보도용으로 제공하는 이미지입니다. 해당 소식을 다루는 기사에서, 원본 형태 그대로, 지정 크레딧과 함께 사용합니다.

| 출처 | 주요 이미지 | 사용 조건 |
| --- | --- | --- |
| 기업 뉴스룸·프레스킷 (예: [Intel](https://newsroom.intel.com/press-hub), [Siemens](https://press.siemens.com/global/en/node/5312), [ZEISS](https://www.zeiss.com/pressphotos)) | 신제품, 시설, 경영진 | 기업별 약관 확인, 지정 크레딧, 원본 유지 |
| [EurekAlert!](https://www.eurekalert.org/) | 대학·연구기관 연구 성과 | 이미지별 Usage Restrictions 항목 확인 |
| [ESA 웹사이트](https://www.esa.int/ESA_Multimedia/Copyright_Notice_Images) | 우주, 지구관측 | ©ESA 표기, CC BY-SA 3.0 IGO 이미지는 라이선스 링크 추가 |
| 보도자료 배포 서비스 (PR Newswire, 국내 배포 서비스) | 기업·기관 발표 | 함께 배포된 보도자료 내용을 다루는 기사에서 사용 |
| 협회·단체·주최측 보도용 사진 | 경기, 행사, 시상식 | 배포처가 안내한 보도 조건에 따라 사용 |

## 사용 전 체크리스트

1. 출처가 자유 이용 출처 또는 보도용 제공 출처 목록에 있는지 확인합니다.
2. 개별 이미지의 라이선스와 이용 조건을 확인합니다.
3. 원본 형태를 유지합니다. 변형은 변경 허용 라이선스에서만 합니다.
4. 지정 크레딧을 이미지 바로 아래에 표기합니다.

## 권리자 요청 대응

1. 요청을 받으면 해당 이미지를 바로 내리고 회신합니다.
2. 이미지 출처와 이용 조건을 확인합니다.
3. 이용 근거를 제시하거나, 대체 이미지로 교체한 뒤 협의합니다.

## 오늘판에서의 구현

| 가이드 | 구현 |
| --- | --- |
| 출처 목록 | `rules/image_sources.yaml` → `image_sources` 테이블. 목록에 없는 출처는 저장 단계에서 거부 |
| 개별 이미지 표기 기준 | 이미지마다 `license`, `usage_terms`, `credit`을 따로 저장. Commons는 파일별 메타데이터, NASA는 항목별 저작권 표기를 읽는다 |
| 원본 유지 | 표시용 파일은 비율을 유지한 축소본만 만든다(자르지 않음). `modifiable`이 아닌 이미지는 화면에서도 자르지 않고 여백을 둔다 |
| 크레딧 | 웹·이메일 모두 이미지 바로 아래 `<figcaption>`에 지정 문구 그대로. 링크가 필요한 라이선스는 링크를 붙인다 |
| 보도용 범위 | `scope_slug`가 같은 글에만 붙는다 |
| 분야별 순서 | `priority` 절. 자동 검색 출처(NASA, Commons, 스톡, 자체 그래픽)는 워커가 찾고, 나머지는 관리 화면에서 등록한 이미지 중에서 고른다 |
| 권리자 요청 | `/images/request` 접수와 동시에 내림(이미지 주소가 바로 404) → 접수 회신 메일 → 관리 화면에서 근거 제시·복원 또는 대체 이미지로 교체 |
